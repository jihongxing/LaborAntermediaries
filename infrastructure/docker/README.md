# 容器配置预留目录

## 用途

预留经过验证的 Dockerfile 与环境编排配置；当前无容器构建文件。开发数据库 Compose 位于 [backend/compose.yml](../../backend/compose.yml)。

## 必须遵守

- 配置需明确构建上下文、镜像版本、非 root 运行、健康检查、资源限制和持久化方式。
- 密钥通过环境或密钥设施注入；与 CI 引用路径、后端端口及 `/api` 前缀保持一致。

## 禁止事项

- 禁止将凭据、日志、生产数据打入镜像，禁止使用不可追踪的镜像替代正式版本。
- 禁止未经确认删除持久卷、暴露数据库或把缺失的 Dockerfile 宣称为已就绪部署能力。
