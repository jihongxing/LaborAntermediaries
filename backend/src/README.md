# 后端源码与测试

## 用途

- `main/java/`：应用入口、`common` 公共契约与工具、`foundation` 基础能力，以及按业务职责归位的 `modules/identity`、`modules/demand`、`modules/bidding` 首批纵向切片。
- `main/resources/`：应用配置、日志配置、Flyway 数据库迁移。
- `test/java/`：单元测试、Web 基础能力测试和 PostgreSQL 集成测试。

## 必须遵守

- 按 [后端接入约定](../README.md)使用认证上下文、组织隔离、幂等、审计、私有文件和可靠任务能力。
- 源码、配置与测试同步变更；迁移采用新增版本并验证升级路径，测试数据必须合成或脱敏。
- 先确认需求与技术方案再接入业务模块，不在通用模块硬编码业务规则。

## 禁止事项

- 禁止关闭租户拦截、伪造可信用户上下文，或在日志和异常响应中暴露敏感内容。
- 禁止在资源目录存放真实私钥、数据库密码、生产数据和构建报告。
- 禁止用内存数据库测试结果代替需要 PostgreSQL 行为验证的集成测试。
