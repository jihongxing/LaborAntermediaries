# 根目录运行日志

## 用途

存放从仓库根目录启动应用或工具时产生的本地运行日志。后端目录启动产生的日志见 [backend/logs](../backend/logs/README.md)。

## 必须遵守

- 除本说明外，日志保持 Git 忽略；采用轮转、保留期和容量限制。
- 分享故障证据前脱敏；长期运维记录进入 [运维文档](../docs/04-运维阶段/README.md)。
- 删除日志前确认排障、审计与保留要求，不把生产日志当作可随意清理的临时文件。

## 禁止事项

- 禁止记录或提交密码、令牌、密钥、完整身份信息、银行账户和敏感请求正文。
- 禁止在此保存源码、数据库备份或唯一业务凭证。
