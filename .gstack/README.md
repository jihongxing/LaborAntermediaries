# 本地浏览器工具产物

## 用途

保存 gstack 浏览器操作生成的截图、控制台日志、网络日志与审计记录；不是项目需求或长期验收档案。

## 必须遵守

- 网页浏览遵守仓库约定，使用 gstack `/browse`。
- 除本说明外，目录内容保持 Git 忽略；需长期保存的证据先脱敏，再归入对应阶段文档并建立索引。
- 清理前确认没有正在运行的工具依赖相关文件，且需保留的证据已经迁出。

## 禁止事项

- 禁止提交 Cookie、Token、个人信息、客户页面截图或网络请求中的敏感数据。
- 禁止将此处文件作为唯一需求来源或唯一验收依据。
- 禁止在此维护应用源码、正式制度或生产配置。
