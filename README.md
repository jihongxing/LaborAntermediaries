# 劳务供应链交易平台

连接用工方与合规劳务供应商，围绕真实用工需求、应标选标、人员供给、履约确认和结算对账建立可追溯的交易与协作网络。项目当前处于需求整理与产品设计阶段；原有的劳务中介管理 SaaS 能力和代码是建设基础，不代表交易平台全链路已实现。

## 产品定位与边界

- **服务对象**：用工方发起需求并选择供应商；劳务公司应标、组织供给与履约；经纪人和工人按相应授权参与。
- **核心流程**：需求发布 → 应标与中标 → 供给与排班 → 考勤和工时核验 → 结算、对账与回款追踪。
- **平台职责**：提供交易撮合、流程协同与可信数据基础设施，不替代劳务供应商承接履约，也不默认承担付款、放款或担保责任。
- **未来方向**：商业保理相关撮合、数据支撑和应收账款管理是可选增值渠道，尚非当前上线范围；相关规划费率不属于现行已批准收费规则。

产品范围、收费审批状态与未来路线分别以[平台 PRD](docs/02-开发阶段/产品设计/PRD-v0.1.md)、[商业模式与收费标准](docs/02-开发阶段/产品设计/商业模式与收费标准-v0.1.md)及[产品战略路线与可选增值渠道](docs/02-开发阶段/产品设计/产品战略路线与可选增值渠道-v0.1.md)为准。

## 本地开发

```bash
git clone https://github.com/jihongxing/LaborAntermediaries.git
cd LaborAntermediaries/backend
mvn test
```

后端环境与启动条件参见 [backend/README.md](backend/README.md)。前端各目录当前不一定具备可执行工程，请勿将规划中的技术栈或功能清单当作已上线能力。
