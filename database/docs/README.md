# 数据库专题文档预留目录

## 用途

预留数据库决策、验证结论和专题说明。现有 [分区策略](../partition-strategy.md)、[复制架构](../replication-architecture.md)位于上级目录，属于参考设计，不代表生产已配置。

## 必须遵守

- 先判断能否更新已有文档，避免另建重复规范；跨模块架构方案归入 [技术方案](../../docs/02-开发阶段/技术方案/)。
- 文档标注适用版本、环境、决策状态及验证依据，维护上级入口。

## 禁止事项

- 禁止把建议参数、性能估算和架构草案写成已验证事实。
- 禁止复制维护需求、收费标准或其他已有权威文档，禁止包含生产凭据与未脱敏样本。
