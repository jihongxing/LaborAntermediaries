# 历史客户交付包生成工具

## 用途与现状

`generate_package.py` 生成早期客户定制阶段的 Markdown 与 Word 交付材料。脚本包含旧 SaaS 功能清单，不是当前劳务供应链平台的需求生成器，也不构成最新报价或交付承诺。

## 必须遵守

- 依赖 Python 与 `python-docx`；调用前阅读脚本，核对内置版本、模板内容和输出文件名，不在本次目录维护中自动运行。
- 输出固定指向 `docs/01-售前阶段/报价方案/客户交付包/`，会归档部分旧文件并重新写入生成的 `.md`、`.docx`；运行前备份并确认当前工作区无冲突改动。
- 仅在确需维护历史交付资料时，经复核后从仓库根目录执行 `python tools/customer_delivery_package/generate_package.py`。
- 生成后审查内容与差异，更新对应文档索引；缓存不是正式产物，不提交 `__pycache__/`。

## 禁止事项

- 禁止不检查内容就覆盖当前正式资料，或将生成结果当作已批准需求、收费、合同和验收结论。
- 禁止在模板或输出中嵌入客户隐私、签章、真实账号和敏感商业数据。
