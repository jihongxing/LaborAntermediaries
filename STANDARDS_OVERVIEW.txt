🎯 核心约束速记
┌─────────────────────────────────────────────────────────────────────┐
│                                                                       │
│  Java后端:                                                            │
│  ✅ Controller只做参数校验和转发                                        │
│  ✅ 金额必须用BigDecimal + NUMERIC(10,2)                              │
│  ✅ 所有业务表必须有tenant_id                                           │
│  ✅ 文件≤500行，方法≤50行                                              │
│  ❌ 禁止Controller直接调用Mapper                                       │
│  ❌ 禁止SQL字符串拼接                                                   │
│                                                                       │
│  Vue 3前端:                                                           │
│  ✅ 组件名必须多词、PascalCase                                          │
│  ✅ 文件≤300行，方法≤50行                                              │
│  ✅ Props必须定义类型和默认值                                           │
│  ❌ 禁止直接操作DOM                                                    │
│  ❌ 禁止console.log提交到仓库                                          │
│                                                                       │
│  Flutter移动端:                                                       │
│  ✅ Widget文件≤500行                                                  │
│  ✅ 使用const构造函数                                                  │
│  ✅ 优先使用final而非var                                               │
│  ❌ 禁止使用print()                                                   │
│  ❌ 禁止硬编码颜色和尺寸                                                │
│                                                                       │
│  数据库SQL:                                                           │
│  ✅ 表名、字段名小写+下划线                                              │
│  ✅ 金额字段必须用NUMERIC(10,2)                                        │
│  ✅ 所有业务表必须有tenant_id                                           │
│  ❌ 禁止用DOUBLE PRECISION存金额                                       │
│  ❌ 禁止不加WHERE的UPDATE/DELETE                                      │
│                                                                       │
└─────────────────────────────────────────────────────────────────────┘
