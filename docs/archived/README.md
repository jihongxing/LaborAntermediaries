## 📋 归档规则

### 什么文档需要归档？

1. ✅ **历史实现记录** - 如P0/P1能力实现完成文档
2. ✅ **老版本需求文档** - 已被新版本替代的需求文档
3. ✅ **已废弃的技术方案** - 曾经讨论过但未采用的方案
4. ✅ **重大变更记录** - 架构调整、数据库迁移等重大变更

### 什么文档不需要归档？

1. ❌ **临时文档** - 如会议记录、讨论草稿
2. ❌ **代码实现文档** - 代码本身已说明
3. ❌ **重复文档** - 内容已合并到核心文档

## 📅 归档时间

每季度末（3月/6月/9月/12月）进行一次文档归档：
1. 将本季度完成的重要文档移动到对应季度目录
2. 删除重复/过期文档
3. 更新README索引

## 🔍 如何查阅归档文档

归档文档不常查阅，但如果需要查看历史信息：

1. 根据时间找到对应季度目录
2. 查看该季度的文档列表
3. 阅读相关文档
