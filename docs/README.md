## 🚀 项目概况

### 核心价值

将劳务中介公司原本依靠微信群和Excel表格运作的业务流程，搬到线上系统进行标准化管理。

### 业务模式

连接四方的平台：
- **用工企业**（工厂）：需要工人
- **劳务公司**（系统主要用户）：中间服务商
- **招聘渠道**：内部专员 + 外部经纪人
- **求职者/员工**：找工作的人

### 产品形态

多租户SaaS系统，MVP阶段先服务一家公司，架构上从第一天就按全国推广设计。

### 技术端口

- **Web后台**：管理员、财务、项目经理
- **移动App**：驻场、项目经理、内部招聘专员
- **小程序**：外部经纪人、求职者/员工
- **企业端**（P1）：用工企业确认工时、对账

## 📁 文档使用指南

### 如何查找文档？

1. **按阶段查找**：先确定当前处于哪个阶段（售前/开发/交付/运维），进入对应的阶段目录
2. **按类型查找**：需求、报价、设计、测试等，在各阶段目录下的子目录中
3. **按关键词搜索**：使用IDE的全局搜索功能（Ctrl+Shift+F）

### 如何贡献文档？

1. **遵循命名规范**：
   - 英文文件名小写+连字符（如 `requirements-draft-v0.2.md`）
   - 中文文件名可直接使用中文（如 `劳务中介管理系统-模块化报价方案.pdf`）

2. **遵循目录结构**：
   - 按阶段分类，放到对应的子目录
   - 会议纪要、变更记录等放到 `00-项目管理/`

3. **版本管理**：
   - 重要文档更新时增加版本号（如 v0.1 → v0.2）
   - 旧版本移动到 `归档文件/`

4. **更新索引**：
   - 新增重要文档后，更新各阶段的 `README.md`
   - 更新本文档（主索引）的快速导航
