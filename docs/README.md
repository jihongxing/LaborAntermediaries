## 🚀 项目概况

### 核心价值

通过统一交易流程和可核验数据，连接用工单位与合规劳务公司，降低需求发布、供应商选择、项目履约协同及结算对账成本。

### 业务模式

交易网络参与方：
- **用工单位**：定义真实需求、选择供应商并确认约定履约结果
- **劳务公司**：应标并依据实际合同组织合规供给与履约
- **个人经纪人/招聘渠道**：按劳务公司授权协助人员供给，不直接替代劳务供应商
- **工人**：参与岗位履约并形成可核验的工时与报酬记录
- **平台**：提供交易组织、数据核验、计费、对账及状态追溯基础设施

### 产品形态

连接用工单位与合规劳务公司的多边交易平台，围绕真实需求、供应商应标、履约核验、分类结算和资金状态构建完整交易链路。

> 当前业务需求以[自主推进需求基线 v0.4](01-售前阶段/需求分析/requirements-draft-v0.4.md)和配套 PRD 为准；商业模式与客户收费规则只以[唯一商业模式文档](./02-开发阶段/产品设计/03-账单与资金/商业模式与收费标准-v0.1.md)为准。人天管理费维持0.5–3.0元固定档位（每0.5元一档），模拟器目前默认1.0元；前0.3元为平台基准，超额部分按平台/用工方3/7、2.5/7.5、2/8封顶的三档**边际分段累进**分成，于2026-10-24获批为最终分成方案。具体区间和公式只在唯一文档维护；规模统计范围和结算周期、财税与收取结算细则仍待确定，不表示模拟器已更新或收费已上线。100元线索解锁价格已批准，但收取结算规则批准并配置前不得实际上线收费。外部激励另以[奖励制度 V1.0](00-项目管理/经营制度/人事经理贡献奖励与跨企业渠道推荐奖励管理制度-v1.0.md)维护：方向已批准，具体实施待审；1元示例和49%预算情景不替代收费及分账基线，不授权对个人自动计提或付款。v0.3 中“只从用工方回款分账扣收”“统一管控账户/T+0”仍为历史方案，不作为当前默认决定。

### 技术端口

- **Web**：平台运营审核与组织管理、复杂配置、批量考勤核对及结算工作台
- **独立 App**：项目经理、驻场和授权人员的现场履约、考勤异常核验与协同，属于完整平台范围
