# 02-开发阶段

> **范围说明（2026-10-20）**：本目录的旧开发周期、团队估算和 P0–P3 模块计划来自客户定制阶段，不能视为当前自主推进计划。项目定位为劳务供应链交易平台，而非以劳务公司内部管理为核心的 SaaS；当前产品范围以[自主推进需求基线 v0.4](../01-售前阶段/需求分析/requirements-draft-v0.4.md)和[PRD v0.1](./产品设计/00-产品全景/PRD-v0.1.md)为准。新增模块应明确其对交易、履约、数据可信、单位成本或持续收费的贡献；工程拆分不得缩减完整平台、履约、资金或独立 App 范围。

**阶段说明**：本目录承载自主推进的平台产品设计、技术方案、实现与验证文档。

**当前状态**：🔵 已进入首批实现与验证；BP-01～BP-03 按业务包清单推进，后续业务仍按完整依赖逐包放行。

## 📅 开发阶段计划

> 以下周期、团队构成与 P0–P3 排序来自原客户定制估算，仅供历史追溯；不得作为当前自主推进的排期或范围决定。当前业务依赖顺序见 PRD“开发顺序与依赖”一节。

**预计开发周期**：19周（约4.5个月）

### 阶段划分

| 阶段 | 周数 | 主要工作 | 交付物 |
|------|------|---------|--------|
| **需求评审** | 1周 | 细化PRD，技术方案评审 | PRD终稿、技术方案 |
| **UI设计** | 2周 | 原型图、UI设计稿 | 设计稿、组件库 |
| **基础架构** | 2周 | 搭建开发环境、基础框架 | 脚手架、CI/CD |
| **模块开发** | 12周 | 分模块并行开发 | 各模块代码 |
| **集成测试** | 2周 | 联调、压测、Bug修复 | 测试报告 |

### 模块开发优先级

**P0（第一批，4周）**：
1. 用户权限模块（基础）
2. 基础数据模块（企业/项目/岗位）
3. 招聘管理模块（核心）
4. 员工管理模块（核心）

**P1（第二批，4周）**：
5. 考勤工时模块
6. 工资管理模块（核心）
7. 借支管理模块（核心）
8. 消息通知模块（基础）

**P2（第三批，4周）**：
9. 渠道结算模块（核心）
10. 财务管理模块
11. 合同管理模块
12. 保险管理模块

**P3（优化阶段）**：
13. 统计分析模块
14. 系统配置模块
15. 运维监控模块

## ⚠️ 开发阶段风险

| 风险 | 应对措施 |
|------|---------|
| 需求频繁变更 | 建立变更管理流程，评估影响后再实施 |
| 技术难点攻坚时间长 | 预留15%风险准备金，提前做技术预研 |
| 多端并行开发进度不一致 | Web先行，移动端跟随，小程序最后 |
| 人员流动导致进度延误 | 代码规范严格，文档完整，降低交接成本 |
| 第三方服务不稳定 | 关键服务准备备选方案 |
