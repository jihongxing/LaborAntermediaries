# 劳务供应链交易平台产品战略路线与可选增值渠道 v0.1

- 文档状态：战略规划，非当前上线范围
- 编制日期：2026-10-22
- 适用范围：平台中长期产品路线、商业保理等可选增值渠道及角色边界
- 当前定位：劳务供应链交易、履约协同与可信数据基础设施

> 本文用于记录已确认的中长期方向，不改变当前产品定位、当前开发范围或现有收费规则。商业保理目前是未来可选的增值渠道，不代表平台当前已经成为保理商、资金方、放款方或任何形式的付款保证人。

## 1. 当前定位不变

平台当前仍以以下能力为核心：

1. 连接用工方与劳务供应商，形成真实、可追溯的劳务交易网络；
2. 支持需求、应标、中标、供给、排班、考勤、工时、结算和对账；
3. 沉淀经过授权、确认和审计的数据，为交易协同和经营决策提供依据；
4. 按《商业模式与收费标准》执行现有平台服务费及其他已批准规则。

商业保理相关能力只能建立在真实交易、真实履约和已确认结算的基础上，不能反向驱动虚构交易、提前确认收入或改变当前业务责任边界。

## 2. 三阶段推进路线

### 阶段一：交易数据与融资撮合基础设施

**阶段目标**：先把劳务交易和履约数据做真实、完整、可验证，为未来融资合作提供基础，但平台不直接提供融资。

**主要能力**：

- 建立需求、合同、中标快照、项目、人员、考勤、工时、结算和回款数据链；
- 维护用工方与劳务供应商之间的应收账款台账；
- 提供融资需求登记和保理机构/资金方撮合入口；
- 按授权生成标准化融资资料包；
- 记录融资申请、询价、审批、签约、放款和回款状态；
- 提供撮合服务费和数据支撑服务费的计费基础，但实际收费须另行审批并完成合同配置。

**平台边界**：

- 不直接提供融资本金；
- 不承诺融资成功、最低融资金额或固定融资利率；
- 不承担用工方付款责任、劳务供应商回购责任或融资差额补足责任；
- 不因维护数据或撮合流程而自动成为债权人、保理商或资金托管方。

### 阶段二：保理协同与应收账款管理平台

**阶段目标**：在具备稳定交易数据和合作机构后，增强债权确认、融资协同和回款管理能力，仍优先采用合作机构承接资金和风险。

**主要能力**：

- 应收账款明细、债权确认和争议金额管理；
- 用工方确认、转让通知和授权留痕；
- 多家保理机构的融资方案询价、比较和状态跟踪；
- 融资额度、融资比例、账期和可融资金额的规则化展示；
- 回款核销、部分回款、逾期、争议和异常处理；
- 重复融资、重复转让和同一应收账款多头占用的风险校验；
- 为合作保理机构输出授权范围内的交易与履约数据。

**平台边界**：

- 保理机构负责资信审核、债权受让、融资决策、放款和风险处置；
- 平台负责流程、数据和协同，不替代保理机构完成尽调和授信；
- 资金流原则上由具备相应能力和资质的合作机构管理；
- 平台不得将数据核验结果表述为融资担保或付款承诺。

### 阶段三：产业金融与商业保理生态

**阶段目标**：在未来具备合规主体、风险管理体系、机构合作能力和充分业务数据后，再评估更深度的产业金融增值模式。

**可选能力**：

- 关联商业保理主体参与特定业务；
- 联合保理、反向保理或供应链金融产品；
- 基于真实应收账款的资产池管理；
- 产业资金、银行、保理机构和劳务供应商的多方协同；
- 更深度的回款账户、额度、风险和资产运营管理；
- 面向大型用工方或核心企业的定制化融资协同方案。

**前置条件**：

- 明确实际业务主体、资金来源、债权关系和风险承担方；
- 完成法律、监管、税务、会计、数据授权和反洗钱等专项评估；
- 建立客户准入、交易真实性、反欺诈、集中度、逾期和催收机制；
- 明确平台与保理主体、资金方、用工方及劳务供应商之间的协议关系；
- 通过独立审批后才能进入产品建设或商业试点。

## 3. 未来可选增值渠道：商业保理相关服务

商业保理是平台未来可选的增值渠道，不是当前平台定位的替代品。未来可围绕以下服务形成收入：

| 增值渠道 | 服务内容 | 当前状态 |
|---|---|---|
| 融资撮合服务 | 连接劳务供应商与保理机构/资金方，协助询价、资料整理和流程跟踪 | 未来可选；费率待审批 |
| 融资数据支撑服务 | 提供经过授权的交易、履约、结算、应收账款和回款数据 | 未来可选；费率待审批 |
| 应收账款管理服务 | 提供台账、债权确认、转让通知、回款核销和异常跟踪 | 阶段二评估 |
| 风险数据服务 | 提供履约稳定性、结算及时性、争议率、回款表现等数据指标 | 阶段二评估 |
| 机构接入服务 | 为多家保理机构提供标准化接口、资料包和业务协同能力 | 阶段二评估 |
| 产业金融解决方案 | 面向核心企业和大型劳务供应链提供定制化金融协同 | 阶段三评估 |
| 商业保理业务 | 由合规主体直接承接应收账款融资、债权管理或相关金融业务 | 阶段三后置评估 |

## 4. 0.2% 与 0.3% 的规划性收费

经本次方向确认，暂按以下方式作为未来可选收费方案进行产品规划：

- 融资撮合服务费：计划按实际融资金额的 **0.2%** 计收；
- 融资数据支撑服务费：计划按实际融资金额的 **0.3%** 计收；
- 原则上以实际放款为收费触发条件，未放款的申请不产生该两项费用；
- 部分放款按实际放款金额计算；
- 两项费用与融资利息、折价费、保理管理费、账户费和其他资金成本分开列示；
- 最终收费对象、发票主体、税务口径、退款规则和结算时点须经专项审批并写入合同后，方可上线实收。

上述费率属于未来可选渠道的规划参数，不属于当前已批准的现行平台收费规则。当前收费仍以《商业模式与收费标准-v0.1.md》为唯一依据。

## 5. 不改变现阶段定位的原则

1. 商业保理是建立在交易和数据基础设施之上的可选增值服务，不取代劳务交易平台主线；
2. 当前产品优先建设真实交易、可信履约、应收账款台账和数据授权能力；
3. 平台不因提供融资撮合或数据支撑而自动承担融资、付款、回购、担保或垫资责任；
4. 任何融资状态不得覆盖或改写原始交易、履约、结算和回款事实；
5. 没有真实合同、真实履约和用工方确认的金额，不得作为可融资应收账款；
6. 商业保理能力必须采用独立的角色、状态、账单和审计链，不与工资、供应商结算和现有平台服务费混账；
7. 只有完成合规评估、机构合作和专项审批后，才能从规划阶段进入试点或生产阶段。

## 6. 关键决策待后续确认

- 0.2% 和 0.3% 的最终计费基数是实际融资金额还是应收账款本金；
- 费用由劳务供应商承担、保理机构承担，还是按合同分摊；
- 平台是否仅提供撮合和数据服务，或由关联合规主体参与保理；
- 是否支持有追索、无追索、反向保理等不同产品；
- 用工方是否必须在线确认债权和转让通知；
- 回款由保理机构管理，还是仅向平台同步状态；
- 同一应收账款是否允许拆分融资，以及如何防止重复融资；
- 何时启动阶段二和阶段三的专项评审。
