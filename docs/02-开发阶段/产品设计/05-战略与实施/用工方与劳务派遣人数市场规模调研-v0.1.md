# 用工方与劳务派遣人数市场规模调研 v0.1

**调研日期**：2026-10-24

**状态**：公开资料研究，不是已验证客户数、获客承诺或业务实施批准。

**目的**：从需求侧寻找可复核的市场基数，区分行业存量、外部用工需求、平台可服务市场与实际可获得市场。

## 一、结论先行

**可以取得全国行业企业数量、从业人员数量，以及按从业人员规模分组的法人单位数量。它们比从某个区的派遣许可证密度外推全国，更适合作为需求侧筛选起点。**

1. **本轮核实的全国制造业基数是 2023 年末企业法人单位 404.8 万个、从业人员 10481.4 万人。**这是第五次全国经济普查公报数据，不是 2026 年现值，也不是实际使用劳务派遣的企业或派遣员工数量。[S1]
2. **更接近集中用工客户的筛选基数：制造业从业人员 100 人及以上的法人单位 149,342 个，其中 300 人及以上 40,428 个。**这是根据经济普查年鉴人数分组表加总的结果，不是官方发布的“派遣用工企业总数”。[S3]
3. **若先选纺织、服装、皮革制鞋、家具、文教工美体育娱乐用品五个候选行业，行业企业法人单位合计约 69.2 万个，从业人员约 1570.0 万人；对应 100 人及以上法人单位合计 23,473 个。**行业篮子是本研究自选，不是官方“全国劳动密集型企业总数”。[S1][S3]
4. **本轮尚未取得可核验、同一统计口径的全国实际采用劳务派遣用工单位数量，以及逐年派遣员工人数序列。**这表示证据尚不充分，不表示主管部门没有统计。不得用行业全部员工、招聘人次或外包人员替代。[检索边界见第五节]
5. **平台现行准入侧重合规外包，派遣数据只能作为相邻市场证据。**需求侧 SAM 应继续筛选可经营区域、适配业务、可采购需求和年度可收费履约量；不能把全国所有派遣用工直接视为本平台市场。

## 二、全国行业基数：知道哪些行业里有多少企业和员工

下表均为 **2023 年末**数据，来自第五次全国经济普查公报。数量单位分别是“万个企业法人单位”和“万人从业人员”；不包含把个体经营户直接混入企业数的处理。[S1][S2]

| 行业 | 企业法人单位（万个） | 从业人员（万人） | 用于市场研究时的意义 |
|---|---:|---:|---|
| 制造业全部 | 404.8 | 10481.4 | 工厂型用工的广义行业背景，不与其下细分行业重复相加 |
| 纺织业 | 14.9 | 384.5 | 候选行业，仍需筛选工厂规模、区域和实际采购方式 |
| 纺织服装、服饰业 | 19.5 | 449.2 | 同上 |
| 皮革、毛皮、羽毛及其制品和制鞋业 | 8.8 | 250.6 | 同上 |
| 家具制造业 | 10.9 | 198.6 | 同上 |
| 文教、工美、体育和娱乐用品制造业 | 15.1 | 287.1 | 包含不同生产组织和工艺，不能全部视为劳动密集型 |
| 计算机、通信和其他电子设备制造业 | 17.4 | 1047.9 | 电子装配等方向的行业背景；不表示全部企业为劳动密集型 |
| 装卸搬运和仓储业 | 10.6 | 142.6 | 仓储相关采购的候选行业，需识别实际采购主体 |
| 邮政业 | 3.0 | 157.9 | 不能由法人数量直接推导网点数量或采购项目数 |
| 住宿和餐饮业全部 | 71.2 | 893.6 | 广义背景，不与其下餐饮业重复相加 |
| 其中：餐饮业 | 52.0 | 614.2 | 法人不等于门店或集团采购账户 |
| 物业管理 | 37.5 | 854.3 | 应判断该企业在交易中是采购方、服务交付方还是两者兼有 |

**这些员工都不是“已确认派遣员工”。**也不能把不同行业人员总量不加区分地乘以一个全国派遣比例，称为官方派遣人数。

五行业候选篮子的加总：

- 企业法人单位：14.9 + 19.5 + 8.8 + 10.9 + 15.1 = **69.2 万个**。
- 从业人员：384.5 + 449.2 + 250.6 + 198.6 + 287.1 = **1570.0 万人**。
- 公报数据已取舍小数，上述结果是公布值加总，不应写成精确到个位的企业或员工数。

该篮子没有穷尽食品加工、电子装配等其他可能适配的行业，也没有完成岗位劳动密集程度识别，因此既不是全部劳动密集型市场，也不是当前 SAM。

## 三、缩小到有集中用工可能性的单位：百人以上与三百人以上

来源为《中国经济普查年鉴—2023》第一卷综合篇，表 1-17《按行业（大类）、从业人员组距分组的法人单位数》。**此表口径是“法人单位”，第二节公报使用“企业法人单位”，两者应保留原始名称，不能无说明地当成完全相同的集合。**[S3]

### 3.1 制造业整体

| 从业人员组距 | 法人单位数（个） |
|---|---:|
| 100–299 人 | 108,914 |
| 300–499 人 | 19,491 |
| 500–999 人 | 13,146 |
| 1000–4999 人 | 7,181 |
| 5000–9999 人 | 440 |
| 10000 人及以上 | 170 |
| **100 人及以上：以上六组加总** | **149,342** |
| **300 人及以上：后五组加总** | **40,428** |

**解释：全国存在约 14.93 万个百人以上制造业法人单位，其中约 4.04 万个达到三百人以上。**这比直接把 404.8 万个制造业企业全部视为潜在集中采购客户，更适合构建第一版名单筛选框架。

100 人门槛只是本研究选择的集中用工筛选条件，不是法定中型企业划分，也不是实际外部用工需求的证明。表中的从业人员也不能未经定义核验就改称“直接签劳动合同的员工”。

### 3.2 五个候选行业中的百人以上法人单位

部分行业的大人数档存在 NA 单元格，不能将 NA 当作零直接求和。因此，下列公式统一使用表 1-17 的“行业法人单位总数减去百人以下四档”，推导百人及以上合计，不推测 NA 对应的单个档位数值。[S3]

| 行业 | 100 人及以上法人单位（个） | 总数减去百人以下四档 |
|---|---:|---|
| 纺织业 | 6,364 | 149488 − 72628 − 39565 − 23414 − 7517 |
| 纺织服装、服饰业 | 6,733 | 195307 − 88466 − 55208 − 34944 − 9956 |
| 皮革、毛皮、羽毛及其制品和制鞋业 | 3,900 | 88319 − 37527 − 24183 − 17274 − 5435 |
| 家具制造业 | 2,452 | 109034 − 58400 − 29819 − 14219 − 4144 |
| 文教、工美、体育和娱乐用品制造业 | 4,024 | 150591 − 80586 − 38634 − 21593 − 5754 |
| **自选五行业合计** | **23,473** | 上述五行业加总 |

这里 23,473 个是 149,342 个制造业百人以上法人单位中的行业子集，不能相加。它可以支持“全国存在数万家具有一定人员规模的候选生产主体”这一研究判断，但不能支持“已有 23,473 家平台可服务客户”。

## 四、如何转为可服务市场 SAM，而不是再次凭比例猜测

### 4.1 家数：逐层筛选，区分服务范围与获客能力

建议将需求侧分为四层：

1. **行业背景**：制造业 404.8 万个企业法人单位及其他目标行业背景。
2. **规模筛选后的候选单位池**：例如百人以上制造业法人单位 149,342 个；五行业子集 23,473 个。
3. **需求侧 SAM**：候选池中，位于计划可经营区域、业务符合平台当前边界、实际存在适配外包采购需求的去重采购主体。
4. **SOM 与实际客户**：在 SAM 内进一步判断销售触达、采用意愿、采购准入和可获得份额；不能把短期签约率当成行业存量。

筛选时保留法人、集团、工厂、项目与采购账户之间的映射。一家公司可能多厂区，也可能一个集团统一采购；法人家数既不是项目数，也不自动等于独立采购决策者数量。

在没有样本之前，第三层仍未知。暂不再为“采用外部用工比例”“可服务比例”填入貌似有依据的全国百分比。

### 4.2 金额：使用适配业务的年度履约量

`年度服务费市场空间 = Σ（目标采购主体适配业务的年度可收费履约人天 × 该业务可实现单价）`

- 人数必须转换为合同、岗位和项目对应的人天，处理淡旺季、轮换、流失、缺勤及重复服务。
- 一个工人一年先后在多家单位工作，不能简单累计成多名独立工人。
- 年度派遣人数即使找到，也不能不加限制地乘 250 天作为全年实际履约。
- 工资流水、供应商营业收入、平台 GMV、含税收费与平台确认收入应分别列示；单价口径遵循现行商业规则。
- 平台当前以适配合规外包业务为边界，不能把派遣相邻市场全部纳入上述可收费人天。

### 4.3 下一轮最值得获取的数据

建议从一个拟切入区域、一个行业篮子开始建立名单，访谈规模只是研究设计，不是已批准试点：

- 采购主体及工厂位置、人员规模、采购是否由集团集中决策。
- 是否采用派遣、真实业务外包或其他用工方式，各方式分别记录。
- 过去 12 个月的项目数、常态和旺季外部用工量、可核验履约人天。
- 现有供应商数量、招采门槛、补员和结算痛点，以及平台收费的实际支付意愿。

实际采用比例应从有明确抽样框的区域名单调查获得。便利抽取几十家访谈可发现需求，但不能包装成全国统计置信区间。

## 五、全国派遣用工单位数量与年度派遣员工人数：本轮证据缺口

### 5.1 目前不能对外确认的数字

本轮未取得可核验的全国用工单位去重总数或连续年度派遣员工原表。此前检索出现过“2019 年服务 48 万家用人单位、派遣 1174 万人”的二手线索，但尚未核到对应主管部门原报告、指标定义及统计覆盖，**不作为已证实数据，不参与本文计算，也不据此外推 2026 年规模**。

下一轮应定向查人社部门人力资源服务业统计原表、劳务派遣年度经营报告汇总、相关统计年鉴或提出政府信息公开申请。需要一并索取：

| 指标 | 必须附带的定义 |
|---|---|
| 使用劳务派遣的用工单位数 | 是否全国、是否法人去重、是否跨供应商去重、是否只覆盖报表机构的客户 |
| 派遣员工数 | 年末在岗、全年平均在岗、全年派遣独立人数、新增人数，还是服务人次 |
| 地区和行业分布 | 按派遣机构所在地还是实际用工地；行业按供应商还是实际用工单位归属 |
| 年度可比性 | 调查覆盖、填报主体、指标定义或统计制度是否发生变化 |

### 5.2 不能混用的五组概念

- **派遣单位 vs 用工单位**：前者是派遣服务供给主体，后者是实际接受派遣劳动的主体。
- **全部从业人员 vs 派遣员工**：经济普查行业就业总量不能直接当作派遣人数。
- **年末存量 vs 年度人数 vs 人次**：必须分别记录，不拼接为一条增长曲线。
- **派遣 vs 外包**：不是同一合同和劳动关系结构，不能不去重相加。
- **行政许可名册 vs 活跃采购名单**：前者主要识别供应侧，不能替代需求侧调查。

**最终建议：可以用“约 14.93 万个百人以上制造业法人单位”描述一个有官方原表支撑的全国候选池；不能用它回答“全国已经有多少家采用劳务派遣”。在实际采购比例未知时，保留 SAM 待验证，比人为给出全国客户数量更可靠。**
