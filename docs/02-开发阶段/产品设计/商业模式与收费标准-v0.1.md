## 1. 商业模式摘要

平台连接用工方与劳务派遣/外包公司。用工方提出需求、选择履约方，并使用平台管理和监督履约过程；劳务派遣/外包公司作为履约方应标、组织人员并交付服务。

平台通过两类收费形成收入：

1. **履约管理费/平台服务费**：由中标并实际履约的劳务派遣/外包公司承担。平台为用工方提供履约过程管理、数据核验、计费、对账等服务。用工方原则上不向平台支付费用。
2. **需求联系人线索解锁费**：由有意联系用工方需求联系人的准入劳务派遣/外包公司支付。用工方明确授权、平台审核且线索仍有效，是线索可售的前置条件；实际收款还须等待收取与结算机制获批并完成合同配置。

两类费用对应不同服务和计费事件；在收费与结算规则获批并启用后，应分别披露、出账、对账和处理退款。线索费不是中标费；支付线索费不保证联系成功、应标成功或中标。平台管理费不是供应商向用工方提交的劳务业务报价，也不是工人工资。

## 2. 收费方与收费原则

| 项目 | 当前规则 |
|---|---|
| 平台管理费/服务费付款方 | 中标并实际履约的劳务派遣/外包公司（履约方） |
| 用工方平台费用 | 原则上不支付平台管理费/服务费；任何例外须负责人另行批准并在审批记录和合同中明确 |
| 线索解锁费付款方 | 经平台准入、购买并解锁授权线索的劳务派遣/外包公司 |
| 费用透明 | 应在相应收费行为发生前展示收费项目、金额、计费依据、适用对象、规则版本及退款/争议处理规则 |
| 费用隔离 | 平台费用与供应商业务结算价、工人工资、保证金分别核算，不混为同一报价或资金科目 |
| 中立性 | 收费或任何收益分配不得影响需求审核、供应商准入、排序、中标、履约评价及争议处理 |
| 资金边界 | 平台账单或支付状态不代表真实到账；平台不因计费而当然承担工资义务、垫资、资金托管或保证责任 |

## 3. 收费项目与建议标准

履约管理费采用用工方主导确定的固定费率档位；线索解锁价格已批准。两项价格分别管理。

| 收入项 | 建议试行价 | 计费对象与触发事件 | 计费依据 |
|---|---:|---|---|
| 履约管理费/平台服务费 | **0.5–5.0 元/有效履约人天；每 0.5 元一个固定档位（已批准）** | 履约方在项目中产生符合项目合同和计费规则的有效履约人天；用工方在需求/项目规则中选择费率档位，供应商应标前知悉并纳入项目经济账 | 按项目合同约定、经核验的实际有效履约人天计费；基准费率 0.5 元/人天，超出基准部分按平台/用工方40%/60%、30%/70%、20%/80%三档分配，默认40%/60% |
| 需求联系人线索解锁费 | **100 元/条授权有效线索/次解锁（价格已批准；收费上线暂缓）** | 准入履约方购买并解锁一条可联系线索 | 用工方对需求联系人及联系方式明确授权、平台审核、线索有效及实际解锁事件记录；并须满足本文件批准的前置条件 |

### 3.1 履约管理费计费公式

`项目当期履约管理费 = 当期有效履约人天 × 用工方确认的固定档位费率`

可选档位为 0.5、1.0、1.5、2.0、2.5、3.0、3.5、4.0、4.5、5.0 元/有效履约人天。用工方主导并在需求/项目规则中确认适用档位；平台负责提供档位、最低服务成本边界、统一计量核验和账单规则；供应商须在应标前明确知悉该档位，并将费用纳入报价及项目经济账。中标后不得追溯提高费率。

`用工方每有效人天分享 = max(0, 项目人天费率 − 0.5 元) × 项目约定的用工方超额分享比例`

`平台每有效人天留存 = 项目人天费率 − 用工方每有效人天分享`

以下比例均按“平台 / 用工方”顺序表示，且仅适用于超出0.5元的部分；0.5元基准始终归平台。支持40% / 60%、30% / 70%、20% / 80%三档，未另行约定时采用40% / 60%。非默认档须在项目规则及合同中明确，不自动升级；同一费率下，分账比例不改变供应商承担的管理费总额。

| 项目费率（元/有效履约人天） | 用工方分享（默认60%） | 平台留存（基准+超额40%） |
|---:|---:|---:|
| 0.5 | 0.00 | 0.50 |
| 1.0 | 0.30 | 0.70 |
| 1.5 | 0.60 | 0.90 |
| 2.0 | 0.90 | 1.10 |
| 2.5 | 1.20 | 1.30 |
| 3.0 | 1.50 | 1.50 |
| 3.5 | 1.80 | 1.70 |
| 4.0 | 2.10 | 1.90 |
| 4.5 | 2.40 | 2.10 |
| 5.0 | 2.70 | 2.30 |

需求计划人数、招聘人数或中标配额均不自动构成有效履约人天，也不构成收入保证。上述平台留存为分账后的收入，不等于平台净利润；尚须扣除平台直接服务成本。

收费基数须以合同约定并核验的实际履约为依据。以下计量细则在正式启用前须另行确认并写入履约方服务合同或项目规则：

- 人天的定义、工作日/自然日口径、班次和跨日处理；
- 部分出勤、迟到早退、休息日、缺勤及补录的折算；
- 争议人天的暂缓计费、确认和追溯调整；
- 重复人员/日期记录的去重规则；
- 计费确认人、确认期限、异议窗口和证据来源；
- 计费周期、债权形成时点、付款账期、逾期处理；
- 税费、发票、退款、冲正及账单锁定后的补差流程；
- 是否设置最低收费、封顶或特殊项目价格。

在上述规则尚未批准前，不应将未经核验或有争议的人天计作已确认应收款。

### 3.2 线索解锁费计费规则

已批准价格为每条授权有效线索每次解锁 100 元。此处收费对应经授权的商务联系机会，不是公开需求本身，也不意味着出售个人数据或承诺成交。由于“收取与结算”事项暂缓，价格批准本身不授权立即开启收款。

收费功能上线前至少须明确：

- 用工方组织对需求信息展示、联系人身份/联系方式披露及供应商联系的授权范围；
- 解锁前展示的脱敏信息、解锁后可见字段及可联系的供应商范围；
- 同一线索可售次数、每家供应商解锁次数、线索有效期和联系频控；
- 线索无效、需求撤回、重复线索、联系方式错误或授权撤销时的退款/补偿规则；
- 供应商投诉、联系人拒绝联系及平台处理流程；

支付解锁费不保证对方回复、建立商务关系、获得应标资格或中标。未完成授权核验或线索有效性审核时，不得收费解锁。
联系人奖励是否实施、收款主体、计算基数和组织授权属于单独的暂缓决策，不是已批准收费规则，也不得自动计提或支付。

## 4. 收益分配规则与待定事项

以下人天管理费分配规则已批准：

1. 每有效履约人天费率的前 0.5 元归平台，不参与用工方分享；
2. 超出0.5元部分支持平台/用工方40%/60%、30%/70%、20%/80%三档，默认40%/60%；项目应在应标前明确适用档次，并按合同及组织授权结算；
3. 用工方分享对象、组织内部归属和支付路径须按用工方组织授权及合同确定，不默认支付给个人员工。

此分账不改变“履约方承担平台管理费、用工方原则上不付平台费”的付款方基线。需求联系人/人事经理是否获得线索解锁奖励、其收款主体及规则仍暂缓，不得自动计提或承诺个人收益。

如考虑实施，审批必须明确收款人是个人还是组织、真实服务内容、组织授权、分配基数/比例、付款流程、披露与审计、税务及利益冲突处理。分配不得与具体供应商中标、评分、审核放行或争议裁决挂钩，不得损害平台对用工方的监督中立性。

## 5. 定价依据与验证方式

0.5–5.0 元/有效履约人天、每 0.5 元一个档位及超出 0.5 元部分平台/用工方40%/60%、30%/70%、20%/80%三档分账（默认40%/60%），已作为商业规则批准，但尚不代表市场已验证该价格区间或各档位的供需接受度。100 元/授权有效线索/次解锁已获批准作为建议试行价，但收取与结算暂缓，故当前不能实际收费。

如后续审批开展试行，重点观察：

- 履约方应标率、中标率、接受管理费后的报价变化和退出/拒标原因；
- 有效计费人天、每项目收费、争议率、坏账率、收款周期及平台服务成本；
- 解锁线索后的有效联系率、回复率、需求转化率、重复/无效线索率和退款率；
- 联系人投诉、供应商骚扰投诉及授权撤回情况；
- 收费对平台供需两侧信任、平台中立性和复购的影响。

后续试行对象、周期、调整阈值及价格调整仍须履行相应审批；不得将试行样本直接表述为普遍市场价格。线索解锁在收取与结算机制获批并完成合同配置前，不得开始实收试行。
