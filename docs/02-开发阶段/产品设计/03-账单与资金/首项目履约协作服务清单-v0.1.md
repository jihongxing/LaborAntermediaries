## 2. 服务与平台销售交付的对应关系

平台销售的是面向供应商的履约管理组合服务，包括项目数据组织、履约核验、差异协同、账单生成和管理报告。用工方只提供其中受委托的现场协作输入，平台仍负责整合、核验及对供应商的管理服务交付与违约补救；平台不因此承担供应商的招工、工资支付或劳务交付责任。

用工方同时可能是平台服务的受益方，甚至符合会计上的客户定义；“供应商付费”不自动排除应付客户对价问题，按配套财税意见单独判断。

## 3. 可采购服务明细

以下为拟议可选清单。首项目逐项勾选“适用／不适用”，并填写实际负责人和输出位置。未选事项不作为付款依据。

| 编号／拟议事项 | 具体委托与边界 | 提交物／频次（建议待签） | 平台验收方法 |
|---|---|---|---|
| S01 项目协作配置 | 依平台任务单整理现场点位、班次映射、协作联系人及数据接口；不以采购决策或开放业务机会作为交付 | 经授权配置表、变更记录；启动时及变更时 | 与任务单逐项比对，检查组织授权、版本和可用性 |
| S02 履约信息结构化协作 | 将已合法取得的现场事件按约定结构整理、校验、提交；不是出售工人个人信息，也不是仅点击确认按钮 | 带来源引用和提交时间的事件明细；建议次工作日 | 核对唯一记录、项目/日期/班次、来源和重复情况；建立抽查索引 |
| S03 数据差异调查与修复协作 | 按平台差异工单调查缺失、重复、跨班记录，提交事实及依据；不要求作有利于平台的结论 | 差异工单、前后版本、原因和来源；按工单期限 | 逐单检查处理轨迹、证据和未解事项，不以“无异议”作为达标条件 |
| S04 现场异常协调 | 按委托联络相关方、组织事实核查、记录协调过程；不得代员工放弃权利、阻断投诉或改变工资审批权 | 异常台账、协作记录、待办及反馈；事件发生后按约定提交 | 验证真实协调行为和反馈完整性；不要求必须消除争议 |

S01、S03、S04并非每个人天都会发生；其实际工作作为周期组合服务交付。**不得为凑齐单人天记录伪造异常**。每个申请计价的人天须有S02的真实协作映射及适用任务的履行记录，周期还须满足所选S01/S03/S04/S05的相关义务。若未履行项目级义务，按事先约定的整改和受影响范围暂缓相应验收，不得事后随意设罚款系数。

### 明确排除

- 用工方自身法定用工管理、安全、考勤、付款审批义务本身；如采购其额外整理或核查服务，须明确新增委托、投入和可区分交付，不能直接重命名全部原有义务。
- 向平台导流、同意招标、中标推荐、指定供应商、为平台提供排他机会或给予不当采购便利。
- 向个人发红包、回扣；对正确投诉、请假、离职或真实争议作负面激励。
- 招聘派遣、工资代发、金融服务、融资担保和独立数据交易，除非另有真实业务、资质及独立合同审批。

## 4. 可计价集合与证据结构

1. **S：销售有效人天集合**。由销售计量规则确认，保留明细ID、确定性排序、原始来源、确认人与规则快照；排序标准签约前确定，不允许事后人为调整档位。
2. **A：采购已验收人天集合**。必须是S的子集，且对应用工方实际完成、平台接受的采购服务。S存在不代表A自动存在。
3. 每条采购明细保存：项目ID、周期、销售明细ID、原始档位序号、任务单ID、交付物ID、来源引用、提交人/时间、验收人/时间、结论及理由。
4. 个人字段采用项目内受控标识；结算导出默认不带完整身份证、银行卡、联系方式。原始证据通过权限控制调阅，依法确定保存与删除期限，不在示例中放真实个人资料。
5. 拒收采购明细不自动否定工人实际出勤，不自动取消供应商销售计费，不允许以此扣工人工资；销售事实另有错误时，另走计量更正。

## 5. 计价与合理性底稿

采购价格拟沿用收费唯一文档中的组织分享算法，作为**真实采购服务的含税计价方法**，不构成自动付款或税前扣除依据。用工方采购服务未验收的人天不计价；其余人天保留在S中的原始档位，不因A缩小而重新排档。新增配置、异常协调等已选工作包含在约定组合价内，不自动另收启动费或工单费。

| 价格合理性项目 | 首项目必须补充的材料 |
|---|---|
| 工作投入 | 实际岗位、投入时数、覆盖班次、工作记录及成本来源；不得倒算虚构人力 |
| 服务能力和复用 | 自有团队／授权资源、并行项目能力、平台工具承担的部分 |
| 外部替代报价 | 独立第三方报价或可比服务条款，注明差异和取得日期 |
| 服务价值 | 平台减少的核验工作、交付质量及供应商获得的管理服务，不能仅写“愿意使用平台” |
| 规模变化依据 | 为什么阶梯价合理；核对规模增大后的投入与价值，比例获批不等于公允价值已证明 |
| 关联交易及客户对价 | 关联关系、利益冲突、是否为可明确区分服务、公允价值及超额部分 |
| 结论与批准 | 业务说明、财务复核、法务审查及负责人签署，附材料索引；当前均待填 |

如实际投入、交付或公允价值不支持拟议采购价，调整服务范围或未来报价后重新签署，**不能靠补合同和开票把不合理支出变成真实服务成本**。

## 6. 交接与完成标志

- 业务完成：任务交付及有证据的验收结论，不以“已付款”代替。
- 结算完成：双方确认可计价集合、价格快照、金额及异议清单。
- 财税完成：财务确认税目、票据、扣除条件与会计口径；待票、待抵扣、税前调整分别标识。
- 支付完成：获授权的对公付款取得成功回执并对账；不能仅凭“指令已发送”判定。
- 本稿完成不等于上述事项完成。正式签约、启动及付款须满足配套意见中的签核门禁。
