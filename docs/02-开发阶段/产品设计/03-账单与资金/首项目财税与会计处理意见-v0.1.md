# 首项目财税与会计处理意见 v0.1

- 编制及依据核查日期：2026-10-24；适用中国大陆境内交易的一般分析。
- 状态：基于用户业务描述的条件性实施意见，**不是税务机关认定、鉴证报告或已完成的项目审计**。
- 证据入口：[服务清单](./首项目履约协作服务清单-v0.1.md)、[采购合同](./履约协作服务采购合同条款-v0.1.md)、[验收结算单](./首项目履约协作服务验收与结算单-v0.1.md)；价格唯一来源：[商业模式与收费标准](./商业模式与收费标准-v0.1.md)。

## 1. 当前结论及尚不能确认的事实

**按当前真实业务方向，应先按“平台销售履约管理服务＋采购用工方履约协作服务”准备合同及证据，而非直接将组织分享称作利润分配、股息、工资或个人佣金。** 这是交易建模判断，不表示只要改名、签合同或取得发票就能扣除。

| 事项 | 当前处理方向 | 最终判断所需材料 |
|---|---|---|
| 平台销售 | 以供应商合同承诺的管理服务为税务及收入分析对象 | 真实销售合同、组合服务输出、供应商权利和平台责任 |
| 用工方采购 | 真实、可区分、合理的受托履约协作服务；不得以仅用平台计费 | 选定任务、投入、交付、验收、价格合理性、组织授权 |
| VAT税目 | 依真实主导服务判断，见下节；不能仅因发票可开6%就选税目 | 实际业务说明、服务合同及分类编码复核记录 |
| 企业所得税 | 真实、相关、合理且凭证符合要求的服务支出按适用规则扣除 | 合同、履约、验收、发票、关联关系及付款等证据 |
| 会计成本／收入 | 先确认制度、总净额及应付客户对价，再作分录 | 会计判断备忘及负责人签核 |

首项目主体、实际投入、交付和公允价格尚未提供，因此目前**不能认定1540.07元或任何真实项目全额均可扣除，也不能保证总额法**。本包给出执行表格，填入真实事实并签核后才能形成项目结论。

## 2. VAT税目与开票决定表

依据2026年起施行的《增值税法》及财政部、税务总局公告2026年第9号服务范围注释，按照实际服务归类。一般计税下，除法律另有规定，销售相关现代服务通常适用6%；实际开票仍须核实纳税人身份、计税方式、优惠和发生时点，不能把统一税率写成结果保证。[依据1、2]

| 交易 | 首选分析路径（不是已核定税目） | 排除／待核实 |
|---|---|---|
| 平台向供应商交付履约管理 | 若实质为信息系统运维、业务流程信息化支持，核对“信息技术服务”中的信息系统／业务流程管理服务；若主导为业务组织管理，核对“商务辅助服务—企业管理服务”等实际适用范围 | 不能仅因有软件就将所有人工管理列信息技术；不能因名称有“管理”就不审实际服务 |
| 用工方向平台交付现场协作 | 依据真实任务，优先核对“商务辅助服务—企业管理服务”等范围是否覆盖受托管理协作；纯信息处理成分须按实际范围再核对 | 不是提供劳动力即“人力资源服务”；不是提供记录即销售无形资产；不得为凑6%虚构咨询服务 |

**项目开票确认栏**：销售税目／分类编码________；采购税目／分类编码________；适用税率／征收率及依据________；是否有优惠或特殊计税________；财务经办／复核／日期________。有歧义时将真实合同和任务说明提交主管税务机关或专业税务人员核实并保存答复，不将本稿当作税目批复。

### 普票与6%专票

- 普通服务发票：本场景一般不能据此抵扣采购服务进项税，但不因此否定真实合理支出的企业所得税扣除。不得推论“所有普票一概不抵扣”，本意见不涉及依法可抵扣的其他特殊凭证。[依据1、3]
- 6%专票：提供方须有合法适用资格；业务真实、发票合规、用于允许抵扣的项目且满足法定条件，才可按规定确认抵扣。收到专票不等于已抵扣，分别记录待核验、待确认和已申报抵扣；不满足条件的进项按适用规则转入成本或作其他处理。[依据1]
- 平台不能仅以买入成本抵减销售额计算销项税；采购服务进项抵扣与差额征税是两回事。没有适用的明确差额计税依据，不得仅对现金价差开票纳税。[依据1]
- 发票、收款和验收有先后差异时，VAT纳税义务发生时点仍依法判断；不能把“验收后付款”写成一切税务时点。[依据1]

## 3. 企业所得税扣除与佣金排查

以企业所得税法第八条真实、相关、合理支出原则及税务总局公告2018年第28号为依据。合同、服务清单、验收结算、合法发票、合理定价及资金资料形成闭环；只有发票而无服务，不支持扣除。[依据3、4]

1. 境内已办理税务登记的企业提供应税服务，按适用规定取得发票；一般应在所属年度企业所得税汇算清缴结束前取得符合要求的税前扣除凭证并留存相关资料。
2. 服务已发生但暂未取得发票，依会计制度按事实暂估不等于税务永久可扣除。年度汇算前仍未补齐且不符合例外／补救规则的，按规定作纳税调整；以后取得凭证依法按补救及追补规则处理，不直接跨年任意列支。
3. 价格合理性须有真实工作、资源投入、可比交易和商业价值依据。按人天或收入比例计价不当然不合理，也不当然证明合理；关联交易须另作独立交易原则审查。
4. 若实际支付只是介绍客户、促成交易、提供业务机会，应重新分析为手续费佣金等，而非继续套用管理服务成本。财税〔2009〕29号对其他企业手续费佣金有特定限额规则，还须核对合法中介主体、排除交易双方及其雇员等对象、合同及转账支付等条件；不能默认用工方符合佣金收款对象条件。同时税务总局公告2012年第15号第三条对从事代理服务且主营业务收入为手续费佣金的企业另有规定，**不能把所有情形一概说成5%限额，也不能靠改合同名称绕过限额**。[依据5、6]
5. 增值税进项能否抵扣、企业所得税成本能否扣除、会计是否冲减收入，是三个独立结论，不互相替代。

建议为每个周期保存“事实—合同任务—交付—验收—计价—票据—记账—付款”索引；依法保存电子原件、版本和有权确认记录。尚未付款的真实债务不因无银行流水就当然不能确认或扣除，但应有其他充分证据，付款后补充闭环。

## 4. 会计判断先于记账

### 4.1 先确定会计制度

一般纳税人是VAT身份，不等于必然执行企业会计准则。首项目先填企业实际采用的会计制度；以下分录仅以执行企业会计准则、相应收入确认条件满足为前提。执行小企业会计准则等，应由会计负责人按实际制度调整，不机械套用准则条款。

### 4.2 主要责任人还是代理人

执行企业会计准则时，按收入准则第三十四条及财政部相关执行要求，审查平台在向客户转让管理服务前是否控制该服务，并综合主要履约责任、风险和定价等事实。重点是**管理服务**而非平台是否承担工人劳务交付。[依据7]

- 支持总额方向的事实：平台自行承诺并整合管理服务、控制所采购协作输入、负责质量核验与服务补救，并有相应风险和责任的实际履行。
- 支持净额方向的事实：平台仅撮合采购、供应商直接接受用工方服务，平台不控制也不承担实质管理服务责任，仅赚撮合手续费。
- 合同写“买卖”不是充分证据，现金差额也不自动是会计收入。会计备忘须列合同、任务控制、实际交付、风险和结论；当前待签。

### 4.3 是否属于应付客户对价

收入准则第十九条要求另查应付客户对价。现有文档同时描述平台为用工方提供管理和监督价值，不能仅因劳务供应商付费就认定用工方一定不是客户。应识别合同客户、实际服务接受方，以及付款对象与客户之间的关系，核对其是否落入该条适用对象；单纯受益也不自动等同于准则客户。[依据7]

- 如构成向客户购买**可明确区分的服务**，并能合理估计公允价值，按真实采购分析；超过该服务公允价值的对价，按准则要求分析冲减收入。
- 如不构成可明确区分的服务，或公允价值不能合理估计，不能直接把全部“分享款”作为采购成本，应按适用准则分析应付客户对价的收入抵减。
- 如用工方并非准则所指相关客户对象，也仍须审查采购真实性和合理性。
- **会计冲减收入不自动获得VAT销售额扣减或红字开票资格**，税务另外判断。

## 5. 3000人天演算与示范分录

> 仅与配套结算单的虚构演算一致，不代表真实项目已发生。假设：平台一般计税，销售适用6%；满足总额确认条件，不存在需要冲减收入的客户对价；采购价税合计1540.07元。暂不考虑其他进项、税额留抵、附加税费、运营费用、坏账和所得税。

| 项目 | 合法6%专票且当期允许抵扣 | 普通服务发票、该采购无可抵扣进项 |
|---|---:|---:|
| 销售含税额 | 3000.00 | 3000.00 |
| 销售不含税收入 | 2830.19 | 2830.19 |
| 销项税额 | 169.81 | 169.81 |
| 采购含税应付 | 1540.07 | 1540.07 |
| 本例采购成本 | 1452.90 | 1540.07 |
| 本例采购可抵扣进项 | 87.17 | 0.00 |
| 本例销项减该项进项 | 82.64 | 169.81 |
| 本例管理服务毛差 | 1377.29 | 1290.12 |

这里82.64／169.81元是**仅考虑本例两笔交易的VAT差额**，不是平台整期法定应纳税额。普通发票开票方适用税率未知，不强行将其1540.07元按1.06拆为可抵扣额。专票栏按示例价税分拆并舍入，实际以合法发票及申报规则核对。

### 示例分录：已交付且符合收入确认条件

| 业务 | 借方 | 贷方 |
|---|---|---|
| 销售管理服务 | 应收账款—供应商 3000.00 | 主营业务收入 2830.19；应交税费—应交增值税（销项税额）169.81 |
| 采购，专票已合规确认可抵扣 | 主营业务成本 1452.90；应交税费—应交增值税（进项税额）87.17 | 应付账款—用工方 1540.07 |
| 采购，普票无可抵扣进项（与上一行二选一） | 主营业务成本 1540.07 | 应付账款—用工方 1540.07 |
| 收到供应商对公款 | 银行存款 3000.00 | 应收账款—供应商 3000.00 |
| 向用工方对公付款 | 应付账款—用工方 1540.07 | 银行存款 1540.07 |

尚未完成抵扣确认、未到纳税义务时点、预收或跨期履约时，按实际制度使用适当的待认证／待转销项等科目，不将本表机械用于所有时间点。采购服务已发生但未到票时，按可支持的可靠金额暂估成本及应付，不凭估计先抵扣进项；取得票后调整暂估、确认税额并留存衔接。具体核算依适用会计制度及增值税会计处理规定。[依据8]

符合相应前提下：

`项目税前会计利润 = 不含税销售收入 − 合规确认的采购成本 − 其他履约成本 − 运营费用 − 税金及附加等损益项目`

企业所得税以调整后的应纳税所得额、亏损弥补及实际适用政策计算，不直接用现金价差乘税率。VAT一般纳税人身份不自动排除或取得小型微利企业所得税资格；本稿不预设所得税优惠，也不承诺净利润。

## 7. 官方依据及使用边界

以下为核查入口；引用用于规则说明，不表示税务机关已审查本平台项目。2026年起服务范围优先使用现行文件，不仅沿用2016年旧注释。

1. [《中华人民共和国增值税法》](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5237365/content.html)：税率、销售额、进项抵扣及纳税义务等；自2026年1月1日起施行。
2. [财政部、税务总局公告2026年第9号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5247431/content.html)：《销售服务、无形资产、不动产注释》等，自2026年1月1日起施行，税目细分核对附件2。
3. [国家税务总局公告2018年第28号](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194804/content.html)：税前扣除凭证管理，重点第二、四至七、九、十二至十七条；真实性、合法性、关联性及取得／补救期限。
4. [国家税务总局12366：企业所得税相关规定](https://12366.chinatax.gov.cn/bzds/054/054-5-1.html)：结合《企业所得税法》第八条及现行实施条例核实实际、相关、合理支出。
5. [财税〔2009〕29号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203388/content.html)：手续费及佣金税前扣除的特定规则，不直接覆盖所有真实采购服务。
6. [国家税务总局公告2012年第15号](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/qysds/201205/t398757.html)：第三条代理服务主营业务相关规定；与上一项合并按实际业务判断。
7. [《企业会计准则第14号——收入》官方全文](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm)：第十九条应付客户对价及可明确区分采购、公允价值；第三十四条主要责任人／代理人与总净额。[财会〔2022〕32号](https://www.mof.gov.cn/jrttts/202212/t20221226_3859893.htm)进一步强调实质判断。签核时会计负责人应附实际适用准则版本及判断，不能以本稿替代。
8. 财会〔2016〕22号《增值税会计处理规定》及企业实际适用会计制度：由会计负责人将适用版本和科目方案附入项目底稿。
