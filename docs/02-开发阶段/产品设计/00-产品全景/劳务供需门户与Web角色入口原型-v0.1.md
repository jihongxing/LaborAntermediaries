## 1. 产品入口

同一 Web 产品提供公共需求浏览和认证后业务空间，但不是一张按角色隐藏卡片的混合工作台。公开网页承担平台介绍、匿名需求发现和组织准入入口；账号、组织成员、角色和具体权限经过独立门禁后，才进入交易工作空间。

| 状态 | 首要任务 | 入口去向 |
|---|---|---|
| 公开访客 | 了解供需平台、筛选匿名公开需求 | 需求大厅、需求详情、登录/注册、组织认证说明 |
| 登录个人 | 继续浏览公开需求、申请组织认证或加入组织 | 个人账号与组织状态 |
| 用工方组织成员 | 管理本组织需求、比较应标、选标和跟进合作 | 用工方业务空间 |
| 劳务供应商成员 | 浏览已授权商机、管理本组织应标和合作 | 供应商业务空间 |
| 平台审核/监督成员 | 处理分派的审核、监督、复核和审计任务 | 独立平台运营入口 |

身份服务、注册登录和组织认证接口由相应服务端提供；当前前端 JWT 调试输入只留在本地开发专用入口，不作为产品登录页。

## 2. 关键页面草图

### 2.1 公共首页 `/`

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 劳务供需平台        需求大厅  平台服务  用工方入驻  供应商入驻   登录 / 注册 │
├──────────────────────────────────────────────────────────────────────────┤
│ 劳务供需协同服务                                                         │
│ 按真实服务需求，寻找合适的劳务合作方                                    │
│ [关键词/工种________________] [区域____] [服务时间____] [搜索需求]       │
├──────────────────────────────────────────────────────────────────────────┤
│ 公开需求                                                     查看全部 →  │
│ 服务需求                       地区          人数     服务周期   截止时间 │
│ 电子装配配套服务               杭州          80–120  11月起     10月30日  │
│ 仓储分拣协作                   佛山          50–80   11月起     11月02日  │
├──────────────────────────────────────────────────────────────────────────┤
│ 用工方发布需求                         劳务供应商申请准入                 │
└──────────────────────────────────────────────────────────────────────────┘
```

需求浏览是首屏的主要功能。页面不展示虚构平台交易量、认证通过率、客户名称或平台担保声明；真实公开列表必须来自需求方单条授权的公共快照。当前本地原型中的需求行使用合成样例并明确标识为预览数据。

### 2.2 匿名需求详情 `/demands/:id`

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ ← 返回需求大厅                                       公开需求 · 应标开放 │
│ 电子装配配套服务                                       杭州 · 80–120人   │
│ 服务期 2026年11月起 / 约3个月      应标截止 2026-10-30 18:00             │
├─────────────────────────────────────────────┬────────────────────────────┤
│ 服务摘要、班次、能力要求、保障与交付边界    │ 需求方身份与联系人         │
│                                             │ 认证组织可见范围受需求授权 │
│ 具体用工主体、精确地址和联系方式不出现在公开页。│ [登录后继续]             │
│                                             │ [申请供应商组织认证]       │
└─────────────────────────────────────────────┴────────────────────────────┘
```

未登录或仅有个人账号时，详情仍使用公共字段白名单。只有已认证并获应标授权的供应商组织成员才进入完整应标视图；主体身份与联系人依该需求的授权级别分别展示。不能用“用户已登录”作为解锁全部详情的判断。

### 2.3 未认证个人账号 `/account`

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 劳务供需平台        需求大厅  账号与组织                                │
├────────────────────┬─────────────────────────────────────────────────────┤
│ 个人账号           │ 账号与组织资格                                     │
│ 组织申请           │ 个人账号已登录        尚未关联通过审核的组织        │
│ 加入组织           │                                                     │
│ 认证进度           │ [申请成为用工方] [申请成为劳务供应商]                │
│                    │ [加入已有组织]                                      │
│                    │                                                     │
│                    │ 认证状态：未提交 / 审核中 / 待补正 / 已通过          │
└────────────────────┴─────────────────────────────────────────────────────┘
```

个人账号可管理自己的组织申请和加入申请，但不因此获得需求方身份、联系方式、应标、选标或项目数据。组织认证与成员岗位授权分别展示，防止把“组织已通过”误当成“当前成员所有操作都已授权”。

### 2.4 认证组织业务总览 `/workspace/employer`、`/workspace/supplier`

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 劳务供需平台       组织切换 / 当前角色                    通知   个人菜单 │
├───────────────────┬──────────────────────────────────────────────────────┤
│ 业务总览          │ 用工方 / 供应商                         本周业务概况 │
│ 需求 / 商机       │ [待处理] [进行中] [即将截止]                           │
│ 应标 / 选标       ├──────────────────────────────────────────────────────┤
│ 合作项目          │ 待办队列                                             │
│ 对账              │ 需求补正 / 应标截止 / 待比较 / 待供应商确认 / 项目异常 │
│ 组织与权限        ├──────────────────────────────────────────────────────┤
│                   │ 最近业务记录：对象、状态、版本、截止时间、下一动作    │
└───────────────────┴──────────────────────────────────────────────────────┘
```

两类组织共享外壳但使用各自的导航和待办：用工方侧重需求、应标评审、选标配额和合作项目；供应商侧重开放商机、应标版本、授予确认和供给项目。角色、成员和项目权限由服务端决定，工作台上的隐藏按钮不是授权边界。平台运营不进入这两个组织空间。

## 3. 页面与路由职责

| 路由 | 页面职责 | 允许身份 |
|---|---|---|
| `/` | 公共平台入口、搜索和精选公开需求 | 所有人 |
| `/demands` | 匿名公开需求大厅与筛选 | 所有人 |
| `/demands/:id` | 公开需求摘要及认证入口 | 所有人；详情字段按阶段裁剪 |
| `/account` | 个人资料、组织申请/加入及认证状态 | 已登录个人 |
| `/workspace/employer` | 用工方业务总览与本组织导航 | 已审核用工方成员，逐项校验权限 |
| `/workspace/supplier` | 供应商业务总览与本组织导航 | 已审核供应商成员，逐项校验权限 |
| `/ops` | 平台审核、监督、回避、证据与复核 | 经分派的平台岗位 |
| `/__dev/console` | 本地服务端接口联调和开发会话 | 仅本地开发构建，不进入产品导航 |

## 4. 当前实现边界

后端尚未定义公共需求授权、公共快照和匿名读取 API，也尚未接入正式身份服务。因此，前端可以完成公共/个人/组织空间的信息架构和交互预览，但不得将公开合成样例称为真实供需数据，也不得通过前端过滤现有 `open-for-bid` 结果来模拟匿名公开。实现真实公开列表前，需要独立评审并落地公共投影、需求方授权撤回、字段白名单、访问审计、缓存失效和匿名查询限流。
