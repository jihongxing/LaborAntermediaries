# 用工方与劳务公司入驻、资质审核需求细化 v0.1

- 日期：2026-10-19
- 状态：专项需求讨论稿；已确认前提与建议规则分列，不代表全部细则已批准。
- 上位文档：[平台 PRD](PRD-v0.1.md)，对应 FR-01、FR-02，并约束 FR-03、FR-04 的操作资格。
- 本次边界：只讨论组织入驻和资质审核，不讨论盈利策略，不缩减履约、资金或独立 App 范围。

## 1. 已确认前提

1. 用工方、劳务公司是同一平台内的两种业务角色，不建设两个互不相通的平台。
2. 两类主体均自主注册、自主提交资料，不以平台邀请或线下签约作为统一入驻前置条件。
3. 审核通过后才能使用对应角色的平台业务能力。
4. 平台使用及审核免费；本模块不得设置入驻费、审核费、补审费或付费加速门槛。本次不重新解释其他业务环节的盈利规则。
5. 按用工方源头、劳务公司应标中标、履约、资金流转的业务顺序细化，不将审核作为删除后续能力的理由。
6. 同一组织当前只能选择用工方或劳务公司一种角色；双角色及角色转换方案不在当前范围，未来有需要再讨论。
7. 用工方支持企业法人、个体工商户、事业单位、分支机构等依法设立主体，不限企业法人。
8. 劳务公司角色当前仅面向合规开展外包、按适用规定完成备案的主体；不将独立招聘中介或派遣作为本次获批的直接承接业务类型。
9. 个人经纪人作为劳务公司的供给渠道，为劳务公司提供人员资源，不直接对接用工方或独立应标。该产品路径不构成违法经营主体的准入豁免。
10. 平台定位是互联网信息撮合，不作为具体外包承接方。本轮不要求确定首批地区、核验渠道和各项处理时限；不将这些运营参数列为继续细化需求的前置问题。

## 2. 建议采用的准入模型

将“账号、组织、业务角色、业务资质、内部权限”分开：

| 层次 | 回答的问题 | 示例 |
|---|---|---|
| 个人账号 | 谁在操作 | 手机号注册的经办人 |
| 组织主体 | 代表哪一家单位 | 企业、个体工商户、事业单位或依法登记的分支机构等 |
| 平台业务角色 | 以什么身份参与 | 用工方、劳务公司 |
| 业务资质 | 可以依法承接什么 | 当前为与实际外包服务相符的备案及其他适用资格 |
| 内部权限 | 此人可以操作什么 | 管理员、需求发布人、应标人 |

“劳务公司”不是一种行政许可证名称；不能仅凭企业名称含“劳务”“人力资源”，就认定具备全部服务资格。

已确认同一组织当前角色互斥。同一主体不能通过重复注册、不同经办人或其他客户端取得第二种角色；内部管理员、应标人等岗位权限不属于第二种组织业务角色。不提供审核后自由切换组织角色的入口。个人可以加入多个获授权组织，不因此改变各组织的角色互斥规则。

## 3. 自助入驻流程

手机号验证注册 → 阅读并同意相应协议及信息处理说明 → 选择一种入驻角色 → 查找或创建组织 → 填写主体与经办人资料 → 按角色补充材料 → 预检 → 提交审核 → 平台核验 → 通过 / 补正 / 不通过 → 开通获批能力。

提交前可更正草稿中的角色选择，但须重新检查材料；已存在的组织不能借新申请绕过角色互斥规则。

### 3.1 账号与组织

- 注册个人账号不等于组织认证通过；未审核账号仍可登录、保存入驻草稿、提交或补正资料、查询进度及申诉。
- 以统一社会信用代码等主体标识查重。同一主体已有组织时，引导申请加入或管理员找回，不重复创建租户。
- 查重提示不得泄露原管理员完整姓名、手机号、身份证件或其他内部资料。
- 申请加入已有组织需由有权管理员确认；管理员失联走独立主体及授权复核，不能仅凭上传营业执照接管组织。
- 账号可以具有多个经授权的组织成员关系；每次业务操作明确当前组织。
- 未通过审核不得通过接口、邀请链接、其他客户端绕过业务门禁。

### 3.2 审核结果

- 通过：明确通过的组织、角色、业务能力、核验时间和依据。
- 补正：一次性列明当前已发现的缺项、原因、修正方式；补交免费，不要求重复上传未变更材料。
- 不通过：提供具体理由与申诉入口，不只展示“审核失败”。
- 外部资料暂无法核验：进入待核验或人工复核，不自动通过，也不将第三方系统故障认定为申请人造假。
- 平台自主注册、人工核验不矛盾；不得把“自主”理解为无需审核。

## 4. 两类角色共同审核材料

以下是建议的平台材料清单。应区分法规要求与平台真实性核验策略，不能全部标为“法律强制”。

| 项目 | 申请人提供 | 平台审核重点 | 性质与边界 |
|---|---|---|---|
| 合法主体证明 | 企业、个体工商户或分支机构的营业执照；事业单位法人证书；其他主体的相应依法设立证明 | 名称、统一社会信用代码等登记标识、主体类型、法定代表人、经营者或负责人、登记状态、材料真实性 | 用工方已确认支持各类依法设立主体；不得所有类型统一要求企业营业执照 |
| 主体联系方式 | 联系人、可验证手机号、联系地址 | 是否可联系、是否与申请组织有关联 | 平台真实性核验策略；不统一强制企业邮箱 |
| 经办人身份 | 姓名、必要身份证明及验证信息 | 操作人真实、身份与验证结果一致 | 按必要范围收集；不默认留存全部证件影像 |
| 组织授权 | 经办人委托证明；法定代表人、经营者或负责人本人办理时核验其身份与代表关系；分支机构按适用权限补充授权 | 授权主体、被授权人、事项、期限、真实性 | 与登录手机号验证不同，手机号不能代替组织授权 |
| 主体异常线索 | 必要时补充说明 | 注销、吊销、冒用、许可证撤销等是否影响本次准入 | 有经营异常或处罚记录不等于一律永久禁止 |
| 真实性承诺与协议 | 授权申请人确认 | 提交人有权代表、材料真实、变更及时更新 | 承诺不能替代许可证或实际核验 |

不将以下材料统一设为所有组织的入驻必填：对公账户、历史工资表、完整员工名册、纳税明细、验资报告、办公场地照片、法人手持身份证、法人人脸视频、入驻保证金。确需补充时，应说明适用场景、必要性和替代核验方式。

## 5. 用工方审核什么

### 5.1 基础角色审核

用工方的角色定义建议为：发布自身真实用工需求，参与评标、履约协同与结算的组织。

- 核验合法设立、经办人身份及授权、联系方式。
- 确认申请人以实际用工需求方身份申请，说明实际用工主体；不能默认允许冒用工厂名称或无授权代发其他单位需求。
- 可采集主营业务、常用用工地区等画像，但不把尚未形成具体岗位、历史招聘规模或支付能力证明设为基础准入硬门槛。
- 普通企业为自身发布需求，不因进入本平台就统一要求提交人力资源服务许可证或劳务派遣经营许可证。
- 有效营业执照不等于任何岗位、工作地点或合作方式都可获准发布。

### 5.2 与具体需求分层审核

入驻时审核“这是谁、谁有权代表”；需求发布时再审核“实际在哪里用工、具体做什么、以何种用工形式合作”。

需求层应进一步核验：实际用工主体、地点、岗位和条件、人数、报酬、合作形式、招聘简章或对应需求说明，以及涉及的行业和岗位特定材料。不得因为组织已认证就免除具体需求审核。

分支机构可以申请用工方角色，不能因其不是独立法人一概拒绝；核验其登记、负责人以及适用的授权和责任关系。代其他主体发单、集团统一采购、工厂与签约单位不同等情形，需要建立授权链及实际履约主体字段，不能默认为自用工。

## 6. 劳务公司审核什么

已确认当前劳务公司角色仅支持合规外包、按适用规定完成备案的主体。先审核共同主体材料，再核验外包服务内容、备案及其他适用资格。以下许可差异用于识别业务实质及防止错放行，不表示同时开放招聘中介、派遣业务。

| 申请业务能力 | 核验材料与依据 | 不能混淆的边界 |
|---|---|---|
| 合规外包，属于适用的人力资源服务外包 | 适用的备案凭证或主管部门可核实备案信息，以及实际服务内容说明；涉及其他法定资格的另核验 | 当前可申请；备案不等于全部业务合法或履约能力担保 |
| 仅招聘、推荐人员等职业中介 | 实质涉及职业中介时需要相应许可 | 当前不据此开放独立承接业务；营业执照或外包备案不能代替许可 |
| 实际劳务派遣 | 识别合同、人员指挥管理及其他实际安排，按适用规定判断 | 当前不以外包名称放行派遣；持派遣证也不自动获得平台外包准入 |
| 外包中同时涉及其他受监管活动 | 分别核验实际活动适用的资格及业务关系 | 不一律要求所有公司“两证齐全”，也不允许备案解锁全部能力 |
| 分支机构申请劳务公司角色 | 主体登记、总分关系及与实际外包活动相符的备案、授权等证明 | 不能仅凭总公司证照直接通过；不得套用用工方主体开放范围自动认定合格 |

- 人力资源服务机构从事职业中介活动适用许可要求；开展人力资源服务外包等业务适用备案规定。普通劳务外包不当然等同于人力资源服务外包，需结合实际合同、人员管理与履约方式判断。
- 备案的法定办理时点和平台开放对应业务的准入时点不是一回事。《人力资源服务机构管理规定》第九条规定有关业务自开展之日起15日内备案；若平台要求先核实备案再开放相应应标能力，应明确这是平台拟定的准入规则，而不是声称法律一律要求提前备案。
- 不将所有劳务公司的注册资本、专职人员或场地材料重新作为平台统一审批条件；行政许可由主管机关作出，平台核验证照，不自行颁发或替代行政许可。
- 人力资源服务许可证按所核验规定为全国范围内长期有效，不应硬性要求填入虚构到期日；支持长期有效及状态复核。具有有效期的其他证照单独记录。
- 证书主体不一致、借证、涂改、已撤销等不能直接通过；公司更名或换证按登记变更及许可记录核实，不简单按名称字符串拒绝。
- 公司规模、驻场人数、服务地区、擅长工种、历史业绩可以作为能力画像；不将未经核实的承诺等同于资质或履约担保。
- 角色获批后，只开放已通过审核的合规外包需求应标能力；拥有额外许可证不扩大平台当前承接范围。
- 本次劳务公司直接承接范围收敛为合规外包。历史文档中的招聘、派遣业务不得据旧稿自动放行；劳务公司为外包履约进行招聘与独立经营职业中介、派遣不是同一概念，不能将必要履约能力一并删除。

### 6.1 个人经纪人渠道边界

- 个人经纪人不是第三种可以直接对接用工方的承接组织，而是经授权关联劳务公司的个人供给渠道。
- 经纪人不能以自身身份发布用工需求、直接应标、取得中标配额或绕过劳务公司直接对接用工方；仅接收所属劳务公司授权的岗位信息并提报人员。
- 组织申请资质不通过时，不能自动转为个人经纪人。自然人如申请该身份，应另行核验身份、关联关系和劳务公司授权。
- 资料暂不齐全与伪造证照、违法经营分开处理。后者不能通过关联劳务公司解除风险限制。
- “个人经纪人”是产品身份，不是法律豁免。若其实际独立经营依法需许可的职业中介活动，不能仅靠劳务公司授权就免除适用要求；具体活动边界需按实际业务确认。

## 7. 审核动作和核验记录

建议平台审核员依次检查：

1. 主体查重与合法设立：比对国家企业信用信息公示系统或其他适用的主管部门登记信息。
2. 经办人真实性与组织授权：区分法定代表人办理、受托经办人办理及后续成员授权。
3. 角色及业务实质：明确自用工需求方、职业中介、派遣或其他服务，不只看企业名称。
4. 许可及备案：通过发证、备案机关的公开信息或其他可核实渠道核对。
5. 给出结论：记录通过范围、缺项、不通过原因及必要的复核。

保存：申请版本、材料版本、审核人、操作时间、核验渠道、查询时间、关键核验结果、理由及获批能力。只保存实现证明与审计目的所必要的信息，禁止无边界抓取外部数据。

外部系统没有公开查询入口时，可通过主管部门可验证的电子证照或人工核实，不把接口尚未对接误标为“已联网认证”。长期有效证照也需要状态复核，不等于永不复审。

审核员只能在明确授权范围查看材料；经办人证件、联系方式和授权文件不作为面向所有入驻企业公开的资料。对外认证标识只说明审核对象和通过范围，不代表政府背书、偿付能力或履约担保。

## 8. 状态与能力门禁

主体、角色申请、各项资质分别管理状态，避免一个证件异常就把整个组织全部停用。

- 申请状态：草稿、待审核、审核中、待补正、通过、不通过、撤回。
- 主体或角色运营状态：正常、复核中、限制新增、停用；停用需要明确原因与权限范围。
- 单项资质状态：待核验、有效、临近到期、已到期、已撤销或失效、信息变更待复核；长期有效证照不进入虚构的到期流程。

| 资格状态 | 可办理入驻与申诉 | 发用工需求、评标 | 新应标 | 已有项目必要履约 |
|---|---|---|---|---|
| 账号注册但组织未通过 | 是 | 否 | 否 | 不自动授予；加入已有获批组织须另行核验 |
| 用工方审核通过 | 是 | 按内部授权及需求审核规则 | 不因用工方身份获得 | 按实际参与关系 |
| 劳务公司及对应资质通过 | 是 | 不因劳务公司身份获得 | 仅匹配获批能力的需求 | 按实际参与关系 |
| 某项资质到期或失效 | 是 | 按角色及风险原因单独判断 | 禁止对应业务新增 | 保留必要记录、申诉、工时、工资和对账；依法处置风险 |

证照到期前提醒、重新提交、变更复审均免费。换证不覆盖旧材料；主体名称、法定代表人、管理员或经营状态变更触发相应复核。法定代表人变更不自动使全部证照失效。

限制新增不等于允许违法业务继续履约。发现涉嫌违法或重大安全问题时，按明确的风险处置和法律要求处理，同时保留必要的工资清偿、证据、投诉和救济路径，不能简单清空数据或锁死账号。

## 9. 验收场景

1. 普通用工企业自主注册，提交主体证明、经办人及授权材料，不因没有人力资源或派遣许可证被机械驳回。
2. 未审核账号能补交资料，不能通过 Web、App、小程序或接口发单、评标、应标。
3. 外包备案及适用资格通过的劳务公司仅能应标当前支持的合规外包需求，不能解锁独立招聘中介或派遣需求。
4. 仅上传招聘中介或派遣许可证不自动通过外包准入；合规外包主体也不被机械要求“两证齐全”。
5. 外包申请的合同和人员管理实质属于派遣时，不能仅凭外包备案解锁派遣业务。
6. 已存在主体的第二个申请人不能重复建租户或夺取管理员权限。
7. 核验渠道故障停留在待核验，不显示通过或材料造假。
8. 长期有效的人力资源服务许可证不要求虚构到期日；其他许可到期只触发相关能力规则。
9. 补正、复核、申诉不收费；任何付费状态不能改变资质结论。
10. 单项资质失效不删除项目、冻结全部工资办理或泄露原提交人的证件；存在风险时按受控方案处置。
11. 更换管理员不继承原管理员个人身份凭据；原账号权限及时失效，操作可审计。
12. 入驻通过后提交虚假或不合法需求，仍应在需求审核环节被拒绝。
13. 同一组织已取得或正在申请一种角色时，不能通过另一个账号重复申请相反角色；被驳回的草稿纠正与既有组织角色转换区分处理。
14. 个体工商户、事业单位及分支机构使用与自身类型匹配的合法设立材料申请用工方，不被强制填写不存在的法定代表人或企业执照字段。
15. 组织申请未通过不自动生成个人经纪人；经纪人无法通过页面、接口、导出或跨组织投递取得未授权的用工方联系方式、应标或直接签约能力。

## 10. 本轮决策与保留边界

| 事项 | 结论 |
|---|---|
| 同一组织双角色 | 当前不允许，二选一；未来有需要再议，不默认提供角色转换 |
| 用工方主体类型 | 支持企业法人、个体工商户、事业单位、分支机构等依法设立主体，按主体类型提交证明 |
| 劳务公司直接准入 | 当前只支持合规外包且按适用规定备案的主体，备案不替代其他实际需要的许可 |
| 个人经纪人 | 通过劳务公司提供人员资源，不直接接触用工方；不得用该身份洗白违法活动或规避许可 |
| 地区、核验渠道及服务时限 | 本轮不展开，也不作固定时效承诺；不是继续需求讨论的阻塞项 |
| 信息撮合定位 | 平台不作为实际外包承接方；自身法律分类按实际活动判断，不按名称自行认定免责 |

核验渠道与审核、申诉流程属于平台自身的审核运营能力，不因不承接具体外包业务而消失。此处保留核验记录、补正、申诉和状态复核要求，但不要求现在确定地方渠道、复审周期或处理天数。

下一次再细化“审核通过的用工方如何形成有效需求”，不在本次扩展岗位字段、竞标定价、履约或资金方案。

## 11. 官方依据与适用说明

以下为2026-10-19实际读取的官方部门公开文本，适用于中国大陆相关业务的需求分析，不替代对具体地区和业务的专业核验。公开转载文本不足以证明法规状态已被穷尽检查，上线前应复核现行有效性及地方执行要求。

| 官方文本 | 本次核验重点 |
|---|---|
| [《网络招聘服务管理规定》，人社部令第44号，平顶山市人社局公开文本](https://rsj.pds.gov.cn/contents/44485/690203.html) | 第九、十、十三条：平台从事网络招聘的资质和公示要求；第十五、十七条：招聘信息真实性及主体、经办人身份与委托证明审查 |
| [《人力资源服务机构管理规定》，人社部令第50号，广州市人社局公开文本](https://rsj.gz.gov.cn/zcfg/flfg/content/post_10505541.html) | 第五条：职业中介许可；第九条：特定服务备案及派遣适用专门规定；第十条：人力资源服务许可证全国长期有效；第十二条：分支机构书面报告；第二十八条：服务外包不得以外包名义按派遣形式用工 |

平台自身若开展职业中介或网络招聘，还需核实其自身适用的行政许可、相关电信业务及公示要求；不能把入驻企业的证照当作平台自身资质。免费注册、免费审核不直接决定是否免于这些要求。此处仅记录准入相关依赖，不展开其他商业或建设范围。

2026-10-19补充核对《人力资源服务机构管理规定》第五、二十一、二十四条：法规按实际活动区分职业中介与信息收集发布；信息发布同样涉及内容审查及投诉处理要求，不能以信息发布名义实际从事职业中介。当前含竞标、人员提报与履约协同的整体设计是否构成相应服务，需要结合运营实质判断。本稿不作“信息平台当然免许可、免审核”或“个人经纪人当然免许可”的结论。
