### 日志记录

**日志级别**：
- **ERROR**：系统错误，需要立即处理
- **WARN**：警告信息，需要关注
- **INFO**：一般信息，用于审计
- **DEBUG**：调试信息，仅开发环境

**日志保留策略**：
- ERROR日志：保留180天
- WARN日志：保留90天
- INFO日志：保留30天
- DEBUG日志：保留7天
