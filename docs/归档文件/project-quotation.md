## 一、项目概述

### 1.1 项目背景

贵公司作为一家专业的劳务派遣与人力资源服务公司，目前业务流程依赖微信群和Excel表格进行管理，存在以下痛点：
- 招聘渠道难以追溯，撞单纠纷频繁
- 工时核算复杂，工资发放效率低
- 返费计算繁琐，经纪人结算不透明
- 数据分散，项目利润难以准确统计

### 1.2 项目目标

本项目旨在为贵公司打造一套专业的劳务中介管理系统，实现业务全流程线上化管理：
- 📱 **三端协同**：Web管理后台 + 移动App + 微信小程序
- 🔗 **全程追溯**：从招聘到离职，每个环节可追溯
- 💰 **自动计算**：工资、返费自动计算，闪电发薪
- 📊 **数据驱动**：实时数据看板,项目利润一目了然

### 1.3 系统架构

```
┌─────────────────────────────────────────────┐
│          Web管理后台（PC端）                 │
│   管理员、财务、项目经理使用                │
│   核心功能：工资核算、返费结算、数据看板     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│          App移动端（iOS + Android）          │
│   驻场、项目经理、内部招聘专员使用           │
│   核心功能：录工时、审批、现场办理入离职     │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│          微信小程序（求职者+经纪人）         │
│   外部经纪人、求职者、在职员工使用           │
│   核心功能：报名、录工时、查返费、看工资     │
└─────────────────────────────────────────────┘
```
