## 🗂️ 当前需求整理事项（自主推进）

### 待评审与细化

- [ ] **评审自主推进需求基线与 PRD**
  - 确认产品战略、完整业务边界和责任分工
  - 对建议逐项采纳、调整或驳回并记录决策

- [ ] **细化用工方需求源头**
  - 明确有效需求形成、真实性审核和发布交接
  - 保证招标目标、应标承诺、中标条件、验收与结算口径一致

- [ ] **细化中标后的履约与资金规则**
  - 定义供给来源、人员状态、考勤、有效履约与有效计费人天
  - 按合同和机构能力明确分类账单、资金回执及异常处理

### 持续维护

- [ ] 核对原客户资料的知识产权、授权与保密边界
- [ ] 维护竞品、运营成本和真实需求获取的验证记录
