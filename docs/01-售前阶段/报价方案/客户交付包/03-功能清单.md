## 5. 本期明确不包含或以条件为前提的内容

| 内容 | 口径 |
|---|---|
| 临工市场接口 | 以第三方接口文档、测试环境、账号和联调支持可用为前提；第三方平台改造和收费不含 |
| 保险公司接口 | 本期包含保险类别和参保信息基础管理；具体外部接口需另行确认 |
| 闪电发薪支付通道 | 本期不默认包含支付通道、资金托管或牌照相关能力 |
| 电子签 | 本期包含合同记录和附件管理；电子签平台对接需另行确认 |
| 企业现有系统对接 | 不默认包含，需在需求评审阶段单独确定 |
| 数据迁移 | 以约定模板和数据量为准，超出范围另行评估 |
| 运营效果 | 不承诺业务量、报名量、利润或纠纷下降比例 |

## 6. 确认方式

客户确认时应在每个模块下确认：功能是否包含、业务规则、角色权限、数据字段、第三方依赖、验收数据和不包含项。确认后新增或修改内容按照《商务条款》的需求变更流程处理。
