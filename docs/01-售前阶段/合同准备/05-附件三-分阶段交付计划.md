# 附件三：分阶段交付计划

**合同附件编号**：附件三  
**文档性质**：合同附件，具有法律效力  
**适用合同**：劳务中介管理系统开发合同  
**项目总价**：¥140万元（方案B）

---

## 🎯 交付计划说明

### 计划目的

本计划明确项目各阶段的：
1. **交付什么**：每个阶段的交付物清单
2. **什么时候交**：每个阶段的时间节点
3. **怎么验收**：每个阶段的验收标准
4. **收多少钱**：每个阶段的付款金额

### 核心原则

- **分阶段交付**：不是一次性交付全部，而是分6个阶段逐步交付
- **验收付款绑定**：每个阶段验收通过后，才触发付款和下一阶段开始
- **时间可控**：每个阶段都有明确的时间期限
- **风险分散**：客户分批付款，开发方分批交付，降低双方风险

## ⚠️ 风险控制条款

### 延期责任

| 延期原因 | 责任方 | 处理方式 |
|---------|--------|---------|
| 开发方未按时完成开发 | 开发方 | 计入开发周期，可能触发违约金 |
| 客户未按时完成验收 | 客户 | 逾期视为验收通过，触发付款义务 |
| 客户未按时付款 | 客户 | 暂停下一阶段，延期不计入开发方周期 |
| 需求变更导致延期 | 客户 | 延期不计入开发方周期 |
| 不可抗力 | 双方免责 | 顺延工期 |

| 情形 | 暂停内容 | 恢复条件 |
|------|---------|---------|

| 上线款未到账 | 不开通正式账号 | 付款到账后1个工作日内开通 |
| 验收款未到账 | 按逾期处理 | 支付款项+滞纳金 |
