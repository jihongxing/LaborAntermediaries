### P0-3：岗位同步规则

**问题**：劳务公司发布的岗位，哪些需要同步到临工市场？

**选项A：全部同步**
- 劳务公司发布的所有岗位都自动同步
- 优点：简单，不需要选择
- 缺点：可能暴露过多信息

**选项B：可选择性同步**
- 劳务公司发布岗位时，可以勾选"是否同步到临工市场"

- 缺点：需要增加配置项

**选项C：仅中标项目的岗位同步**
- 只有竞标成功的项目，其岗位才同步
- 优点：符合业务逻辑
- 缺点：可能限制招聘渠道

### P0-5：报名渠道归属规则

**问题**：求职者从临工市场报名，渠道归属如何确定？

**场景说明**：
- 劳务公司在自己系统发布岗位，同时同步到临工市场
- 求职者可能从两个渠道报名：
  - 渠道A：临工市场App直接报名
  - 渠道B：经纪人在劳务公司端提报

**选项A：临工市场算"平台渠道"**
- 从临工市场报名的，不属于任何经纪人
- 不给经纪人返费
- 劳务公司节省返费成本

**选项B：按劳务公司规则分配**
- 劳务公司可以配置"临工市场渠道"的返费规则
- 可以给平台返费，或者给内部渠道返费
- 灵活但需要额外配置

**选项C：临工市场带渠道码**
- 临工市场展示岗位时，可以带上经纪人的渠道码
- 求职者点击带渠道码的链接报名，归属该经纪人
- 最灵活，但技术复杂

**具体确认**：
- [ ] 采用哪种方案？（平台渠道 / 劳务公司配置 / 带渠道码）
- [ ] 如果是"平台渠道"，是否给临工市场返费？（是 / 否）
- [ ] 如果给返费，返费比例是多少？（___%）

- [ ] 跨平台报名冲突如何处理？（先报先得 / 按保护期 / 人工裁定）

### P0-6：报名数据去重规则

**问题**：同一个求职者在两个平台报名同一岗位，如何处理？

**场景举例**：
- 王小明在临工市场App报名了"流水线工"
- 3天后，经纪人张三在劳务公司端也提报了王小明

**选项A：先报先得，后续报名拒绝**
- 以第一次报名为准，后续报名直接拒绝
- 简单明确
- 可能影响经纪人积极性

**选项B：保护期机制**
- 第一次报名后，设置保护期（如7天或15天）
- 保护期内拒绝其他渠道报名
- 保护期后允许其他渠道重新报名
- 平衡各方利益

**选项C：按报名状态判定**
- 如果第一次报名未通过面试，允许第二次报名
- 如果第一次报名已入职，拒绝第二次报名
- 复杂但合理

**具体确认**：
- [ ] 采用哪种去重方案？（先报先得 / 保护期 / 按状态）
- [ ] 如果是保护期，保护期多长？（__天）
- [ ] 去重标识是什么？（身份证号 / 手机号 / 身份证+姓名）
